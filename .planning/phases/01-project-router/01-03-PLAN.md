**# /project** — Title

**## Purpose** — One paragraph: Project orchestrator that bootstraps state on first run and routes users to the correct next skill on every subsequent invocation. The single entry point to the project skill suite. Read-only after bootstrap.

**## When to Use** — Bullet list:
- Starting a new project (triggers bootstrap)
- Checking project status ("where am I?", "project status")
- Deciding what to do next ("what's next?")
- After completing a phase and needing routing to the next skill
- When project goals have changed and you need re-planning routing

**## When NOT to Use** — Bullet list:
- When you want to create a PRD (use `/define`)
- When you want to implement code (use `/build`)
- When you want to research a technical question (use `/spike`)

**## Behavior** — Describe the three modes:

1. **Bootstrap (first run)**: Creates `progress.txt` with gate entries and empty milestone/spike sections. Detects greenfield (skips Gate 0) vs brownfield. This is the only time `/project` writes to disk.

2. **Status Report (subsequent runs)**: Reads `progress.txt` and all `milestone-status.txt` files. Displays a structured summary: gate checklist with dates, active milestone with per-feature status, completed/upcoming milestones as one-liners, all spikes. Validates artifact existence (warns if missing) and milestone consistency (blocks routing if divergent).

3. **Routing**: Recommends the next skill to run based on current project state. Shows one primary recommendation plus 2-3 context-sensitive alternatives. Detects natural language re-planning intent (e.g., "goals changed" routes to `/define` in revision mode).

**## Gate WB Handling** — Special behavior: When Working Backwards has not been decided, `/project` offers it with Yes/Skip/Defer options. If previously deferred (Pending), shows a gentle reminder but still displays the full status report.

**## Artifacts** — Table of files /project reads and writes:

| File | Read/Write | When |
|------|-----------|------|
| `progress.txt` | Write (once) | Bootstrap only |
| `progress.txt` | Read | Every invocation after bootstrap |

| Gate artifact files | Read (existence check) | Every invocation (for artifact validation) |
