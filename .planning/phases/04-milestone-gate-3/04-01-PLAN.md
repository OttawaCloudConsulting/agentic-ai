   - Generate `milestones/<NN>-<name>/reviews/gate-3-review.md` checklist (MIL-06). Format per `references/review-checklist-template.md`

   - Update Gate 3 line in `progress.txt` to `[~] Gate 3: Milestone Review  In progress` if not already (MIL-09). /milestone NEVER writes `[x]` to Gate 3 -- only `/project` does this (D-05)
   - Write-ordering: `milestone-status.txt` FIRST, then `progress.txt` (STATE-04)

     ```
     - [ ] Feature 01.3: Password Reset (pending)
     ```

   - Ask "What changed?" to understand the scope change

   - Use the Edit tool to apply targeted changes
