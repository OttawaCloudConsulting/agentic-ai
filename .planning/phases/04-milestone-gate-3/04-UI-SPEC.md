## Not Applicable

Phase 4 (/milestone — Gate 3) produces Markdown prompt engineering files, not a visual interface. The deliverables are:

- `skills/project/milestone/SKILL.md` — flow controller (Markdown)
- `skills/project/milestone/references/*.md` — gate specs, revision mode spec, progress format, checklist template
- `skills/project/milestone/assets/milestone-readme-template.md` — README template
- `docs/skills/milestone.md` — detail documentation
- `docs/SKILLS.md` — catalog entry update

There is no frontend, no UI components, no CSS, no design system, and no visual rendering in this project. The entire codebase is Markdown files consumed by Claude Code as skill instructions.

## Copywriting Contract

Not applicable in the traditional UI sense. However, the following text patterns are defined by upstream decisions and requirements:

| Element | Copy Pattern | Source |
|---------|-------------|--------|
| Prerequisite failure | "Gate 2 must be approved before milestone planning. Run /design first." | MIL-01, /design prerequisite pattern |
| Milestone plan proposal prompt | "Here is the proposed milestone breakdown. Review the grouping, ordering, and sizing." | D-01, D-03, MIL-08 |
| Approval prompt (milestone plan) | Approve / Revise (AskUserQuestion, 2 options) | Established produce-then-review pattern |
| Approval prompt (individual milestone) | Approve / Revise (AskUserQuestion, 2 options) | Established produce-then-review pattern |
| Revision mode entry | "This milestone already exists. Entering revision mode." | D-10 |
| Revision feature checklist prompt | "Which features are affected by this scope change? Select all that apply." | D-11, MIL-11 |
| Completion report | "Milestone NN defined. N features, review checklist generated. Run /milestone again for the next milestone or /project to check gate status." | MIL-09, D-05 |
| Tradeoff callouts | 2-3 key grouping/ordering decisions surfaced before approval | D-03 |

These are interaction prompts within Claude Code conversations, not rendered UI elements.
