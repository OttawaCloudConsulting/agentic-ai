# Project Lifecycle Power

Provides structured workflows for project planning and feature execution. Activate this power when beginning a new project or starting work on a feature.

## Available Workflows

### Start Feature

Begin work on the next feature in the project roadmap. Reads the project's tracking file, identifies the next pending item, extracts requirements, and presents a summary before implementation begins.

See `steering/feature-start.md` for the complete workflow.

### Create Requirements (PRD)

Create a complete project foundation through a structured interview process. Produces requirements documents, architecture specifications, and a feature tracking file through iterative questioning.

See `steering/prd-creation.md` for the complete workflow.

## Onboarding

When first activated, verify:

1. The workspace has a project tracking mechanism (Kiro specs, task list, or similar)
2. If creating requirements, confirm the working directory is the project root
3. Check for existing requirements documents before creating new ones
